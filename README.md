# 🍏 Classic Icons for iOS 18

Простое нативное приложение для генерации конфигурационных профилей (`.mobileconfig`), которое возвращает классические иконки приложений без «стеклянного» и тонированного эффекта iOS 18.

## 🚀 Особенности
- **Никаких ПК:** Собирается автоматически через GitHub Actions в готовый `.ipa` файл.
- **Плавный интерфейс:** Написано на Swift / SwiftUI с учетом оптимизации производительности.
- **Безопасность:** Работает через стандартные профили конфигурации WebClip (без системных уязвимостей).

## 🛠️ Как установить (Сборка через GitHub)
1. Перейдите во вкладку **Actions** в этом репозитории.
2. Дождитесь окончания сборки (`Build IPA`).
3. Скачайте артефакт `ClassicIcons-IPA` и распакуйте архив.
4. Установите полученный `.ipa` файл на устройство (через ESign, Scarlet, TrollStore или AltStore).
